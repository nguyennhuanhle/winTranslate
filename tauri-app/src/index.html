📌 How to use / Cách sử dụng
1. Select text in any app / Bôi đen chữ ở bất kỳ ứng dụng nào
2. Press Ctrl+Shift+T / Nhấn Ctrl+Shift+T
3. View translation & click Copy / Xem bản dịch & bấm Copy
4. Press Esc or ✕ to close / Nhấn Esc hoặc ✕ để đóng
⚙️ System Tray / Khay hệ thống
• Enable — Turn on/off / Bật/tắt dịch
• Target Language — Choose language / Chọn ngôn ngữ đích
• Help — Show this guide / Hiện hướng dẫn này
• Exit — Quit app / Thoát ứng dụng
